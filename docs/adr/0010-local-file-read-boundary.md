# ADR-0010: 本地文件读取的安全边界(host 权限 + OS,只接受绝对路径)

与 ADR-0007(server 不读宿主文件、路径穿越面=0)刻意对照:client 的 `read` 支持本地文件,入参统一为 `uri`——`http(s)://` 走 URL 抓取,`file:///` 绝对 URI 或绝对 OS 路径走本地文件(client 自行读取后经 `POST /read` multipart 上传解析),**相对路径一律返回指令文本不解析**。本地文件**不设白名单目录**:安全边界 = MCP host 的权限层 + OS 权限兜底(agent 显式调用即视为授权,OS 可拒绝)。原因是 agent 读取本地文件路径作为参数是基本能力,强制绝对路径从定义上消除"相对路径相对哪个目录"的歧义与启动/工作目录不一致的错读面;server 侧维持 ADR-0007 不变,此边界只存在于 client。
