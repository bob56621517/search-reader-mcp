# ADR-0001: 单端口整合服务器取代 jina 默认服务

我们没有让各能力各自监听端口(或保留 jina 原 HTTP API 原样),而是用一个整合 HTTP 服务器在**单个端口**(18081)上同时承载 `read/`、`search/`、`mcp/`、`sse/` 四个端点,并在容器启动时以 Dockerfile 修改 CMD 的方式**取代** jina 镜像默认启动的 `crawl.js`。原因是需求明确要求"一个 URL 承载全部、最终只暴露一个端口",且我们以扩展并复用镜像环境为定位。代价:与官方 jina reader 的 HTTP 接口形态不同,不向后兼容其原路由。
